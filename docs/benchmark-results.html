Correctness

The paper's recursion was biased without bound

Cvetanoska & Stojanovski value each path with max(intrinsic, discounted continuation) using that path's own realised future. Every path therefore exercises with hindsight. The error is not noise — it grows with the number of exercise dates and never converges.

Pricing error vs number of exercise dates

Signed error against the exact price, N=100,000 paths. Longstaff-Schwartz replaces the hindsight decision with a cross-sectional regression on in-the-money paths, and the bias collapses to within Monte Carlo noise.

Why a call alone cannot prove this works

For a call on a non-dividend-paying stock, never exercising early is the correct answer — so the test above cannot distinguish a working exercise rule from one that never fires. The put is the real test: early exercise binds, there is no closed form, and a Cox-Ross-Rubinstein tree restricted to the same 20 exercise dates gives an independent reference that shares no code with the Monte Carlo path.

Convergence

Quasi-random sampling buys about an order of magnitude

Both estimators price the same contract. The pseudo-random backends fall off at the textbook O(N−1/2) rate; the Sobol sequence with a Brownian bridge converges markedly faster.

The standard-error column does not apply to QMC

The sd/√N formula assumes independent draws, and a Sobol sequence is deterministic and correlated by construction. At N=10⁶ the QMC backends report a standard error of 0.0143 while their actual error against the exact price is 0.000014 — a thousandfold overstatement. The benchmark prints this warning at run time. A real QMC error bar needs randomised QMC: average over several independent digital shifts and take the standard deviation of the means. That is not yet implemented.

Caveats

What these numbers do not show

  • The GPU is handicapped here. The RTX 5060 runs double precision at 1/64 the single-precision rate, and CUDA 12.4 has no native sm_120 target so the kernels arrive by PTX JIT from sm_80. Everything on the device is deliberately double precision, to make CPU/GPU agreement testable rather than to be fast — the two QMC backends match to 1 × 10−6. On a datacenter part with full-rate FP64 the speedup column should look very different.
  • LSM is low-biased. The fitted exercise policy is suboptimal, so the estimator converges from below. A true confidence interval needs a paired upper bound (the Andersen-Broadie dual), which is not implemented.
  • The pseudo-random streams are not independent. Path seeds are (path_id + 1) × 1234567 on a 2³² LCG, so neighbouring paths walk correlated positions on the same lattice. Replacing this with a counter-based generator (cuRAND Philox) is the next correctness item.
  • Memory now bounds the problem. LSM regresses across paths at each exercise date, so the whole path set must be resident — N×(m+1) doubles, about 176 MB at N=10⁶, m=21. The naive recursion needed none of it.
