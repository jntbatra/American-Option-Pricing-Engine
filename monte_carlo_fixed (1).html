Slide 2

The Problem

⚠ Early Exercise Problem
American options can be exercised at any time before expiry — creating an optimal stopping problem with no closed-form analytical solution.
⚠ Black-Scholes Gap
Black-Scholes gives a closed-form for European options, but no equivalent exists for American options — requiring numerical methods.
⚠ Variance & Convergence
Standard Monte Carlo converges slowly at O(1/√N), so low path counts are noisy. QMC improves stability by sampling more uniformly.
⚠ Compute Bottleneck
Millions of paths and multiple exercise steps drive heavy runtime costs — parallel CPU/GPU backends make million-path pricing practical.
Normal Variates for GBM
Uniform RNG is mapped to N(0,1) via Moro inverse CND, then used in GBM path generation.
🎯 Project Goal
Price American options using Monte Carlo with Gaussian shocks and QMC variance reduction on Serial, OpenMP & CUDA backends.
Slide 3

Core Concepts

01 · American Option
Flexible early-exercise contract
Holder has the right (not obligation) to buy/sell an underlying asset at the strike price at any point up to expiry T. Value ≥ European option always.
02 · Monte Carlo Simulation
Simulate N paths → average outcomes
Generates thousands of stochastic asset price paths; averages discounted payoffs. Converges at O(1/√N) for standard MC, O(log(N)ᵈ/N) for QMC.
03 · Geometric Brownian Motion
Standard stochastic price model
Stock price follows: S(t) = S₀·e^((r−½σ²)Δt + σ√Δt·z) where z is a random variate. Drift r, volatility σ.
04 · Normal Distribution
Gaussian shocks for GBM
PDF: f(z)=1/√(2π)·e^(−z²/2), with z ~ N(0,1). Uniform variates are mapped to normal via Moro inverse CND.
05 · Black-Scholes Model
Foundation pricing formula (European)
Provides a continuation-value proxy: c(S,X,t,v,r). Used to initialize the Bermudan backward induction.
06 · Quasi Monte Carlo (QMC)
Low-discrepancy quasi-random sequences
Sobol sequences + Brownian Bridge replace pseudo-random LCG. Points cover the space more uniformly, giving faster convergence with fewer paths.
Slide 4

Pricing Algorithm

1
Forward Simulation
Generate N stock price paths via GBM over m discrete time steps. Random variates from LCG (standard MC) or Sobol+Bridge (QMC). Each path: one thread on GPU.
S(tᵢ) = S(tᵢ₋₁) · e^((r−½σ²)Δt + σ√Δt·zᵢ)
2
Continuation Value (Black-Scholes Proxy)
Initialize the continuation value using the Black-Scholes call at the last step. We use Δt = T/(m+1) as the Bermudan step size.
cₘ₋₁ = BS(Sₘ₋₁, X, Δt, v, r)
3
Backward Induction
Traverse from expiry backward. At each step take max(intrinsic value, discounted continuation) to model early exercise.
cᵢ₋₁ = max(Sᵢ₋₁ − X, cᵢ · e^(−r·Δt))
4
Averaging & Discounting
Average optimal exercise values across all N paths. Discount to present value: Price = mean(c) · e^(−rT).
Timeline: Forward Paths → Backward Decisions
📐 Moro Inverse CND
Transforms uniform U[0,1] variates to Normal N(0,1). Used in both LCG and Sobol pipelines. Provides higher accuracy than Box-Muller for tail regions.
U ~ Uniform(0,1) → z = Moro⁻¹(U) ~ N(0,1)
Bermudian approximation ✓ m discrete exercise points Upper bound on true American price

OpenMP — CPU Parallelism

Parallel Strategy
▸ #pragma omp parallel for distributes paths across all available CPU threads
▸ Each thread simulates its assigned batch of paths independently — no shared state
▸ Dynamic scheduling with chunk size 64 balances load across unequal workloads
▸ Per-path seed (path + 1) × 1234567u ensures unique, reproducible random streams
▸ Final reduction via omp reduction(+:callValue) — atomic-free aggregation
QMC-OpenMP Variant
Replaces LCG with Sobol low-discrepancy sequences scrambled per-thread. Brownian Bridge transform applied to Sobol output before GBM step. Achieves faster convergence at same thread count.
// OpenMP American Option Core Loop #pragma omp parallel reduction(+:total_sum) { std::vector<double> S(m+1); #pragma omp for schedule(dynamic, 64) for (int path = 0; path < N; ++path) { uint32_t seed = (path + 1) * 1234567u; S[0] = S0; for (int i = 1; i <= m; ++i) { double z = moro_inv_cnd(lcg_next_uniform(seed)); S[i] = S[i-1] * exp(drift + v * sqrt(dt) * z); } double c = bs_call(S[m-1], X, dt, v, r); for (int i = m-1; i >= 1; --i) c = std::max(S[i]-X, c * exp(-r*dt)); total_sum += c; } } double price = (total_sum / N) * exp(-r*T);

CUDA — GPU Parallelism

GPU Execution Model
▸ One GPU thread per simulation path — thousands execute simultaneously via SIMT
▸ 512 threads/block with dynamic block count based on path count N
▸ Warp shuffle reduction aggregates partial sums — avoids atomic contention
▸ Coalesced global memory access, shared memory for partial sums per block
▸ Per-thread LCG seed: (path + 1) × 1234567u
Thread Hierarchy
// CUDA Kernel — 1 thread = 1 path __global__ void american_option_kernel( double* d_partial, int N, double S0, double X, double r, double v, double T, int m) { extern __shared__ double sdata[]; int path = blockIdx.x*blockDim.x + threadIdx.x; double dt = T / (m + 1); double discount = exp(-r*dt); double payoff = 0.0; if (path < N) { uint32_t seed = (path + 1) * 1234567u; double S_path[64]; S_path[0] = S0; for(int i=1; i<=m; ++i) { double z = moro_inv_cnd_device(lcg_next(seed)); S_path[i] = S_path[i-1] * exp((r-0.5*v*v)*dt + v*sqrt(dt)*z); } double c = bs_call_device(S_path[m-1], X, dt, v, r); for(int i=m-1; i>=1; --i) c = fmax(S_path[i]-X, c*discount); payoff = c; } double block_sum = block_reduce_sum(payoff, sdata); if (threadIdx.x == 0) d_partial[blockIdx.x] = block_sum; } // Launch config int threads = 512; int blocks = (N + threads-1) / threads; american_option_kernel<<<blocks,threads,shared_mem_bytes>>>(...);

Normal Variates & Moro Inverse CND

Mathematical Definition
φ(z) = 1/√(2π) · exp(−z²/2)
Mean: 0
Variance: 1
CDF: Φ(z)
Input: u ~ U(0,1)
Sampling: z = Moro⁻¹(u)
Output: z ~ N(0,1)
Why Gaussian for GBM?
▸ Matches the Black-Scholes / GBM assumptions under the risk-neutral measure
▸ Efficient, accurate sampling via Moro inverse CND
▸ Clean baseline for QMC variance reduction comparisons
▸ Heavy-tailed models are future work (Student-t, stable)

Quasi Monte Carlo — Sobol & Bridge

Standard MC vs QMC
Property Standard MC QMC (Sobol)
RNG Type Pseudo-random LCG Low-discrepancy
Convergence Rate O(1/√N) O(log(N)ᵈ/N)
Space coverage Clumping / gaps Uniform / optimal
Path transform Direct GBM Brownian Bridge
Parallelism Per-thread seed Scrambled Sobol
Brownian Bridge Transform
Instead of simulating step-by-step, Brownian Bridge conditions the path on the endpoint and fills in intermediate points. This distributes Sobol variates more effectively across time dimensions — reducing discretization error.
Scrambling for Parallelism
Each OpenMP thread / CUDA block uses a different scrambling matrix applied to the Sobol sequence. Produces statistically independent sub-sequences — enabling variance estimation.
Convergence: MC vs QMC (Actual Benchmark)
MC undershoots at low N; QMC overshoots. Both converge to ~13.29 — QMC stabilises faster (N=1K vs N=100K).
Slide 10

CUDA Optimization Techniques

🔀 Warp Shuffle Reduction
Uses __shfl_down_sync() to reduce partial sums within a warp without shared memory. Avoids bank conflicts. Final per-block sums written to global memory.
🧮 Coalesced Memory Access
Linear thread indexing keeps global writes contiguous for per-block outputs, while full paths stay in thread-local storage to minimize global traffic.
⚙ Block-Level Partial Sums
Each block reduces its paths to a single partial sum in shared memory, then the host aggregates blocks — fewer global writes, no atomics.
🚀 Fast Math Intrinsics
Replaces expf/sqrtf with hardware-accelerated __expf/__sqrtf. Trades tiny precision for 2–4× throughput on transcendental operations — acceptable for Monte Carlo pricing.
📐 Thread Block Sizing
Default launch uses 512 threads/block; blocks scale as ceil(N/threads). Shared memory is sized per warp for reductions.
shared_bytes = num_warps * sizeof(double)

Conclusion & Future Work

Key Findings
✓ Backward induction over Bermudian time steps gives a reliable upper bound on American option price
✓ LCG/Sobol uniform draws + Moro inverse CND provide accurate normal shocks for GBM
✓ CUDA achieves ~33× speedup over serial CPU at 1M paths on T4 GPU — enabling near-real-time pricing
✓ QMC (Sobol + Bridge) converges faster than standard MC at equivalent path counts
✓ Serial, OMP, CUDA & QMC-CUDA produce numerically consistent prices (~13.29 at 1M paths); QMC-OMP has a known scrambling divergence (~12.12)
Future Work
